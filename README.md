# Campus Wi-Fi Intrusion & Rogue Access Point Detection System

## Project Overview

A Python-based cybersecurity monitoring application designed to analyze wireless network traffic, identify suspicious access points, detect potential Evil Twin attacks, and record wireless security incidents.

The system will initially support offline analysis of prerecorded wireless packet capture files (.pcap), with the possibility of live wireless monitoring in future development stages.

## Project Objectives

- Identify unauthorized wireless access points.
- Detect suspicious access points broadcasting duplicate network names.
- Identify potential Evil Twin attacks.
- Maintain a registry of authorized access points.
- Record and categorize security incidents.
- Provide a dashboard for monitoring detected threats.

## Ethical Considerations

The system will be developed and tested using authorized network traffic and legally obtained packet capture files.
